1.1What file I/O is

File I/O means Input/Output: how Python reads data from a file on disk and writes data back to one.

f = open("test_file.txt", "r")

open() gives you back a file object. It's an object, so it has methods (things it can do, like .read()) and properties (facts about it, like .closed).

ArgumentMeaning
nameThe file name or path, e.g. "data.csv"
access_modeWhat you want to do: read, write, append…
bufferingHow much of the file is held in memory at once. You rarely set it.
ModeWhat it does
'r'Read. This is the default.
'w'Write. Wipes the file first.
'a'Append. Adds to the end and keeps old content.
'x'Create a new file. Fails if it already exists.
'b'Binary, for images and other non-text files.
'+'Read and write.

open("test_file.txt")Opens the file in read mode (the default) and returns the file object.
my_file =Stores the file object. This is the handle, not the text.

1.4Handling a missing file with try / except

try:
    file = open("not_file.txt", "r")
    content = file.read()
    file.close()
    print("File contents: " + content)
except IOError as e:
    print("File not found error:", e)
try:Attempt the indented code. If something fails, don't crash.
open("not_file.txt")Runs, fails (the file doesn't exist), and Python jumps to except.
read / close / printNever run, because the line before them failed.

File not found error: [Errno 2] No such file or directory: 'not_file.txt'
Remember: the failing line did run; it ran and failed. The lines after it never ran. That difference tells you where to look when debugging.

1.6read, readline, readlines and strip

with open("School_Enrolment_Data.csv", "r") as fp:
    lines = fp.readlines()

        print("Line: {}".format(line.strip()))
fp.readlines()Reads the whole file as a list of strings, one per line. Each still ends in \n.
for line in lines:Loops through the list, one line at a time.
line.strip()Removes whitespace at both ends, including the \n.
"Line: {}".format(...)Puts the line where {} is. Same as f"Line: {line.strip()}".
MethodGives you
.read()The whole file as one string
.read(15)The first 15 characters
.readline()The next line each time it's called, and '' at the end
.readlines()All lines as a list
Why strip? Each line already has a \n, and print() adds another. Without .strip() you get a blank line between every row.

1.12Unique authorities and the hyphen trap

Question: how many different school authorities are there in 2020-2021?

Why the notebook got 0

df[df['School Year'] == '2020_2021']   # 0 rows
print(df['School Year'].unique())
['2013_2014' '2014_2015' '2015_2016' '2018_2019' '2016_2017' '2019-2020' '2017_2018' '2020-2021']
The trap: older years use _, but 2019-2020 and 2020-2021 use -. Run .unique() on a column before you filter it.
filtered = df[df['School Year'] == '2020-2021']
num_authorities = filtered['School Authority Name'].nunique()
Column values A, A, B, A, CResult
.unique()['A','B','C'], the list
.nunique()3, how many distinct values
.count()5, every non-missing value

The csv version uses a set

import csv
authorities = set()

with open('School_Enrolment_Data.csv') as file:
    reader = csv.reader(file)
    next(reader)
    for row in reader:
        if row[0] == '2020-2021':
            authorities.add(row[2])   # column 2 = authority NAME

print(len(authorities))

A += 1 counter has no memory, so it would count each school. A set remembers what it has seen and ignores repeats. row[1] is the category (Public, Separate…), not the name.

Check yourself
  1. Why can't += 1 count unique things?It doesn't remember which names it has seen, so repeats get counted again.
  2. How do you see the names instead of the count?print(authorities), or for name in sorted(authorities): print(name).

2.1What JSON is

JSON (JavaScript Object Notation) is a text format for storing and sending data. It looks almost exactly like a Python dictionary.

{
  "name": "John",
  "age": 30,
  "emails": ["john@example.com", "john@gmail.com"],
  "address": {"street": "123 Main St", "city": "Exampleville"}
}
JSONPython
Object { }dict
Array [ ]list
String / numberstr / int or float
true / falseTrue / False
nullNone
Why it exists: a CSV is flat, with one value per cell. JSON can nest: John has two emails and an address with its own parts.

2.2dump, dumps, load, loads

FunctionDirectionWorks with
json.dumps(obj)Python → JSONgives back a string
json.dump(obj, file)Python → JSONwrites into a file
json.loads(text)JSON → Pythonreads from a string
json.load(file)JSON → Pythonreads from a file
Memory trick: dump = save out, load = bring in, and the "s" means string. Python → JSON is serializing, and back is deserializing.

2.12The stack explorer

stack = [json_data]

while stack:
    current = stack.pop()
    if isinstance(current, dict):
        for value in current.values():
            stack.append(value)
    elif isinstance(current, list):
        for item in current:
            stack.append(item)
    else:
        print(current)
stack = [json_data]A pile of plates with one plate: the whole JSON.
while stack:Keep going while the pile isn't empty. A for loop runs a fixed number of times, and while runs until its condition is false.
stack.pop()Takes the top (last) item off the pile.
dict → .values()Opens the box and puts its values back on the pile.
list → itemsPuts each item on the pile. elif means "else if".
else: printA plain leaf value that can't be opened.
Why the output starts with "Emily Wilson": last in, first out. The last items added are explored first. Keys are thrown away, so this is for exploring, not for building tables.

R2Mistakes to avoid

Thinking the text disappears when the file closesThe variable keeps it. Only f.read() fails on a closed file.
Mixing up "closed" and "already read"Closed → ValueError. Open but read → ''.
Expecting .write() to add a new lineIt doesn't. Add "\n" yourself.
Using 'w' when you meant 'a''w' wipes the file first. This happened to test_file.txt and data1.json.
Doing maths on CSV textWrap it in int(), and check for '' first.
Filtering on a value without looking at the column'2020_2021' vs '2020-2021'. Run .unique() first.
.count() when you meant .sum() or .nunique()Decide first: counting rows, counting distinct values, or adding values?
Skipping a level in nested JSONaitp_info['projectDetailsTitle'] fails because it's inside 'data'.
Using a key on a list['friends']['name'] fails. Lists need a position: ['friends'][0]['name'].
Keys without quotes, or dots between bracketsWrite ['friends'], not [friends] or .['name']. Names are case-sensitive.
Naming a variable filterIt covers up a built-in. Use filtered.
